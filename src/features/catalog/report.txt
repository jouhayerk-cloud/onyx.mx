
**TITLE**: Research Report: 3D Shape Generation from 2D Masks in Three.js

**1. OBJECTIVE**
To enhance the 3D visualization of "canoe" type products in the `Onyx.mx` application by leveraging 2D segmentation mask data to generate more accurate and realistic 3D models.

**2. BACKGROUND**
The current application renders canoe shapes using a scaled hemisphere (`THREE.SphereGeometry`), which is a rough approximation. The product data, however, contains a `spatialMasks` property with precise 2D top-down outlines of the items, generated by an AI model. This research explores using this mask data to create a data-driven 3D model via extrusion in Three.js.

**3. PROPOSED METHODOLOGY**
The process involves three main steps: Contour Extraction, Shape Definition, and 3D Extrusion.

**3.1. Contour Extraction from Image Mask**
The mask is provided as a base64 encoded grayscale image data URL. To convert this into a vector outline, the following steps are taken:
- **Image Loading**: The base64 data URL is loaded into an `Image` object.
- **Canvas Rendering**: The image is drawn onto an offscreen HTML5 `<canvas>`.
- **Pixel Analysis**: The canvas's `ImageData` is read to allow for pixel-by-pixel analysis.
- **Contour Tracing**: A boundary tracing algorithm, such as the Moore-Neighbor tracing algorithm, is implemented. This algorithm works as follows:
    1. Scan the image pixels to find the first non-background pixel (e.g., alpha channel value > 128). This becomes the starting point of the contour.
    2. From the current point, check its 8 neighbors in a clockwise order.
    3. The first neighbor that is also part of the shape becomes the next point on the contour.
    4. Repeat this process, always starting the neighbor search from the direction of the last move, until the path returns to the starting point.
- **Point Normalization**: The resulting list of pixel coordinates `(x, y)` is normalized (e.g., divided by image width and height) and centered around the origin to create a resolution-independent outline.

**3.2. Shape Definition in Three.js**
The ordered and normalized list of 2D points from the contour extraction step is used to define a 2D shape within Three.js:
- The `(x, y)` points are converted into an array of `THREE.Vector2` objects.
- A `THREE.Shape` is instantiated from this array of vectors. This `THREE.Shape` object represents the 2D top-down profile of the canoe.

**3.3. 3D Extrusion**
With the 2D `THREE.Shape` defined, a 3D object is created using `THREE.ExtrudeGeometry`:
- **Depth**: The `depth` of the extrusion is determined by the product's `height` property.
- **Beveling**: To create a more realistic, curved hull instead of a blocky extrusion, beveling options are utilized. Key `extrudeSettings` include:
    - `bevelEnabled: true`
    - `bevelThickness`: Controls how far the bevel extends from the shape's edge. This can be used to simulate the curve of the hull.
    - `bevelSize`: Controls how far the bevel recedes along the shape's plane.
    - `bevelSegments`: Increases the number of segments in the bevel, creating a smoother curve.
- **Geometry Creation**: The `THREE.Shape` and `extrudeSettings` are passed to the `THREE.ExtrudeGeometry` constructor to generate the final 3D geometry.

**4. IMPLEMENTATION STRATEGY**
- A new helper function, `findContour(imageData)`, has been created within `Onyx.mx` to implement the tracing algorithm.
- The main `init3dViewer` function has been refactored to handle asynchronous mesh creation. When an item's shape includes "canoe", it will first check for mask data.
    - If mask data exists, it will load the mask image, call `findContour`, and generate the extruded mesh.
    - If no mask data is available or if the process fails, it will fall back to the original method of using a scaled `SphereGeometry` to ensure backward compatibility.
- The new mesh is properly centered, scaled, and rotated to fit the viewer.

**5. CONCLUSION**
This approach allows for the creation of highly-specific 3D models that accurately reflect the unique shape of each canoe item, providing a significant improvement in visual fidelity and realism for the online store. It transforms a generic placeholder into a data-driven product representation.
