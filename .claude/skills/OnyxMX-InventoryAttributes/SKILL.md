## 1. Complete Inventory Data Model (`InventoryItemData`)

Defined in [`src/lib/Types.tsx`](file:///c:/Jouhayerk/git/app/src/lib/Types.tsx):

### Identifiers
- `id` (UUID), `rowId`, `itemId`, `itemNumber`

- `bookBarcode`, `bookAqCode`, `bookLandCode` — deterministic codes

### Dimensions
- `weightKg`, `heightCm`, `widthCm`, `lengthCm`

### AI-Generated Fields
- `shortDescription` — single-sentence product summary
- `generatedDescription` — bullet-point format
- `detailedDescription` — HTML marketing copy (1000-1200 chars)
- `generatedColor` — Shopify palette classification (2-3 colors)
- `generatedType` — Shopify product taxonomy category

### Media & Visuals
- `mediaUrls`, `image_urls`, `drive_ids`
- `videoGen`, `usdzUrl`, `glbUrl`
- `generatedPngUrl`, `generatedSvgUrl`

### Spatial/AI Data
- `spatialBoxes2d` — AI-detected 2D bounding boxes
- `spatialPoints` — key points
- `spatialMasks` — segmentation masks
- `localSegmentationMasks`, `cloudSegmentationMasks`

## 2. Vendor Management

### Vendor Registry
Defined in [`src/lib/consts.tsx`](file:///c:/Jouhayerk/git/app/src/lib/consts.tsx) as a hardcoded mapping:
```typescript
vendors = {
  JM: { name: 'JOSE MEZA', color: '#6BCEBB' },
  EM: { name: '...', color: '...' },
  CA: { name: '...', color: '...' },
  ON: { name: '...', color: '...' },
  TE: { name: '...', color: '...' },
  ML: { name: '...', color: '...' },
  // ... additional vendors
}
```

### Vendor ID Extraction
- Parsed from `itemId`: e.g., `EM-001` → `vendorId = "EM"`
- Used for color-coded UI tags, grouping, and crate assignment

### Polish Type Derivation (Shopify Metafield)
```
JM          → "Fully Polished"
TE, EM, ML  → "Partially Polished"
All others  → "Matte"
```

### Adding a New Vendor
1. Add entry to `vendors` object in `src/lib/consts.tsx`
2. Assign: prefix (1-2 letters), full name, display color hex
3. Add polish type mapping in `BatchProcessingWizard.tsx` (`custom.polish_type` logic)
4. Items with matching prefix will auto-associate

## 3. Workbook Versioning

| Workbook | Purpose | State | Tabs |
|----------|---------|-------|------|
| `v326` | **Active operations** | Current inventory | `inventory`, `finance`, `production`, `logistics`, `database` |
| `v825` | **Archive** | Sold/shipped/retired | Legacy format |

- Items move between workbooks via "Archive" action in `DetailsPanel.tsx`
- `WORKBOOK_TABS` constant defines available tabs per version
- Exchange rate location differs by version:
  - v326: `data[1][1]`
  - v825 (legacy): `data[10][3]`

## 6. Color System (3-Layer Pipeline)

### Layer 1: Raw Color
- Vendor-provided color string (e.g., `"GREEN ONYX"`)
- Stored in `color` field

### Layer 2: Cleaned Color
- `cleanColorString()` in `utils.tsx` strips material names
- Removes: `ONYX`, `MARBLE`, `STONE`, etc.
- Example: `"GREEN ONYX"` → `"GREEN"`

### Layer 3: AI Classification
- **Gemini 2.5 Flash** returns 2-3 dominant colors
- Must be from Shopify allowed palette:

```
Black, Blue, Bronze, Brown, Clear, Copper, Cream, Gold, Gray, Green,
Iridescent, Multicolor, Orange, Pink, Purple, Rainbow, Red, Rose Gold,
Silver, Tan, Turquoise/Aqua, White, Yellow
```

### Color Extraction Algorithm ([`colorExtractor.ts`](file:///c:/Jouhayerk/git/app/src/lib/colorExtractor.ts))
1. Render image to HTML canvas
2. Pixel sampling with background filtering (removes studio backdrop)
3. Euclidean distance mapping to Shopify palette
4. Returns closest 2-3 matching palette colors

### Special Rules
- **NEVER** select "Black" for translucent items (Cylinder Pendants)
  - Dark studio backgrounds get misclassified as item color
- Stone veining patterns may warrant "Multicolor"
- Consider material translucency in classification

## 9. AI Processing Pipeline

### Models
Job → model map in `src/lib/ai/models.ts` (content, segmentation, translate: `gemini-2.5-flash`; bgReplace: `gemini-3.1-flash-image-preview` with `gemini-2.5-flash-image` fallback). Change models there only.

### Cutout pipeline (Catalog Hub and Add Entry Generate)
1. **Local**: background removal (`@imgly/background-removal`) → mask
2. **Vector tracing** → SVG boundary path
3. **Gemini segmentation** (`buildSegmentationPrompt`) for layers when selected
4. **Output**: PNG cutout and an SVG that embeds the cutout with an outline (`cutoutSvgDocument`), uploaded to Google Drive → `generated_png_url` / `generated_svg_url`

### Description Generation Rules
- **Short**: Single sentence, no articles ("a", "the"), strict JSON output
- **Detailed**: 1000-1200 chars, HTML (`<p>`, `<ul>`, `<li>`), premium artisanal tone
- **FORBIDDEN**: Word "lamp" → use "Luminarie" or "Light Fixture"
- Emphasize: Mexican stone craftsmanship, natural translucency
- Output must include `box_2d` bounding boxes and polygon coordinates

### Video Processing ([`videoAI.ts`](file:///c:/Jouhayerk/git/app/src/lib/videoAI.ts))
- Videos >10s chunked via in-browser FFmpeg
- Each chunk → Gemini for background removal
- Generates clean semantic clips of inventory items
